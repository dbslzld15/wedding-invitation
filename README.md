### 아직 임시인 부분

- **연락처:** 모두 010-0000-0000이며 전화·문자 연결은 비활성화되어 있습니다.
- **계좌:** 은행·예금주·계좌번호 미입력. 계좌 복사 기능은 아직 없습니다.
- **참석 응답:** 화면 체험용이며 입력값을 저장하거나 전송하지 않습니다.
- **문구:** 초대 글·두 사람의 이야기·감사 편지는 샘플입니다.
- **주차:** 무료 2시간은 확정, 등록 방법·등록 위치·차량 진입 안내는 미확정입니다.
- **추가 사진:** 현재 갤러리 10장과 별도 보너스 사진 1장이 들어 있습니다.
- **효과 · 음악:** 꽃잎 효과는 사용하지 않으며, 배경음악은 미정으로 꺼져 있습니다.

## 로컬 확인 · 날짜별 미리보기

index.html을 브라우저에서 열어 기본 화면을 확인할 수 있습니다. 클립보드 등 일부 기능은 HTTPS 또는 로컬 서버 환경에서 확인하는 것이 좋습니다.

로컬 서버나 배포 주소 뒤에 아래 쿼리를 붙이면 날짜별 화면을 확인할 수 있습니다.

- ?preview=standard — 실제 현재 날짜 기준 일반 화면
- ?preview=event-day — 예식 당일 화면 시뮬레이션
- ?preview=after-day — 예식 이후 화면 시뮬레이션

미리보기는 실제 날짜를 바꾸지 않으며, 날짜 시뮬레이션 여부를 화면에 표시합니다. 날짜 판단은 기기의 현재 시각을 Asia/Seoul 시간대로 변환한 값을 사용합니다.
