# 박우진 · 이정은 모바일 청첩장 7차 시안

- 예식: 2027년 6월 13일 일요일 낮 12시 40분 (Asia/Seoul)
- 장소: DMC타워웨딩 2층 그랜드볼룸홀
- 주소: 서울특별시 마포구 성암로 189 중소기업DMC타워
- 무료 주차: 2시간 (사용자 확인)
- 메인 영문: WOOJIN & JUNGEUN (한 줄)

## 확인 방법
index.html을 브라우저에서 열면 됩니다. 서버·설치가 필요 없습니다.

## 현재 상태
- 공개 배포하지 않은 디자인 시안입니다.
- 첨부 사진은 웹용으로 축소했습니다. 원본은 수정하지 않았습니다.
- 꽃잎 및 배경음악 없음.
- 부모님 성함은 실제 정보로 반영했습니다. 신랑 아버지 박봉만·어머니 김향송, 신부 아버지 이승용·어머니 정미현입니다. 연락처는 임시이며 전화·문자 버튼은 비활성화했습니다.
- 계좌는 미입력입니다. 송금·계좌 복사 기능은 아직 없습니다.
- 참석 응답은 화면 체험만 가능하며 입력값을 저장·전송하지 않습니다. 실제 공개 전 외부 설문이나 백엔드 연결이 필요합니다.
- 추가 사진 11장 중 9장을 선별하고 기존 메인과 함께 총 10장을 갤러리에 넣었습니다. 흐림이 강한 D21031B7 컷과 역광이 강한 B23F88B2 컷은 이번 시안에서 제외했습니다. 원본은 수정하지 않았습니다.
- 갤러리는 썸네일 지연 로딩·확대·이전/다음 버튼·키보드 좌우키·모바일 좌우 스와이프를 지원합니다. 선택 목록은 photo-selection.json에 있습니다.
- 잔디에 나란히 앉은 사진을 이야기 영역에, 따뜻한 오후 사진을 마지막에 배치했습니다.
- 한글 고운돋움, 영문 Quicksand를 로컬 WOFF2로 포함했습니다. 라이선스는 assets/fonts/*-OFL.txt에 있으며 폰트를 받기 위한 외부 접속은 필요 없습니다.
- 초대 글·이야기는 창작한 임시 문구입니다.
- 카카오톡 공유용 OG 이미지의 절대 URL과 실제 도메인은 배포 전 설정해야 합니다.
- noindex는 검색 제외 요청이며 접근 제한이나 개인정보 보호 기능이 아닙니다.

## 향후 GitHub Pages 배포
실제 연락처·계좌·사진 공개 범위를 확인하고, 파일을 저장소 루트에 올린 뒤 Settings > Pages에서 master 브랜치 / (root)를 선택합니다. 무료 공개 저장소에 올리면 소스·사진·수정 이력이 공개되므로 시안 업로드 전 확인이 필요합니다. 현재는 GitHub의 dbslzld15/wedding-invitation 비공개 저장소에 업로드했습니다. 공개 배포는 아직 하지 않았습니다.

## 3차 수정
- 메인 영문 이름은 성을 제외하고 WOOJIN & JUNGEUN 한 줄로 표기했습니다.
- 스크롤은 브라우저 기본 동작을 유지하며, 글·사진이 20px 아래에서 약 0.8초 동안 부드럽게 나타납니다. 한 번 나타난 내용은 다시 숨기지 않습니다.
- 동작 줄이기(reduced motion) 설정, JavaScript 미지원, 인쇄에서는 모든 내용을 효과 없이 표시합니다.
- 사용자 첨부 약도를 오시는 길에 넣었습니다. 누르면 확대 창, 원본 크기 확대와 스크롤 이동을 지원합니다. 원본 약도는 수정하지 않았습니다.

## 4차 수정
- 양가 부모님 실명을 초대 글, 연락처 창, 마음 전하실 곳에 반영했습니다.
- 전화번호는 010-0000-0000, 계좌 정보는 미입력 상태를 유지합니다.
- 공개 저장소 업로드나 배포는 하지 않았습니다.

## 5차: 하객을 위한 작은 재미와 예식 당일 모드
- 메인 영문 이름 버튼을 5번 누르면 갤러리에 없던 보너스 사진이 열립니다. 키보드 Enter/Space로도 가능합니다. 이미지 파일 자체의 접근을 제한하는 기능은 아닙니다.
- 하객 미션은 7차 수정에서 제거했습니다.
- 편지는 한국 시간 2027-06-13 00:00부터 열리고, 이후에도 열어 볼 수 있습니다. 문구는 창작한 샘플입니다. 정적 사이트의 날짜별 연출일 뿐, 소스 접근을 차단하는 보안 기능은 아닙니다.
- 예식 당일(한국 시간 6월 13일)에만 상단에 시간/홀/주차/대중교통/지도/주소 복사/약도 확대를 우선 표시합니다. 하단 고정 버튼은 위치·약도 / 주차 / 연락처로 전환됩니다.
- 평소에는 기존 감성 청첩장을 유지합니다. 예식 이후에는 기존 화면으로 돌아오고 감사 편지는 계속 열립니다. 날짜는 기기의 현재 시각을 서울 시간으로 변환해 판단합니다.
- 화면이 열려 있어도 30초마다 날짜 모드를 다시 확인하며, 탭으로 돌아올 때도 갱신합니다.
- 디자인 검수용 URL: ?preview=event-day (당일), ?preview=after-day (예식 이후), ?preview=standard (실제 현재 날짜). 미리보기 상태는 화면에 명시합니다.
- 전화번호와 계좌는 여전히 임시이며, 주차 등록 방법·주차장 차량 입구 안내는 추가 확인 후 반영해야 합니다.
- 서버 저장, 쿠키, 로컬스토리지, 추적 스크립트는 추가하지 않았습니다. 공개 배포도 하지 않았습니다.

## 6차: 지도 서비스 아이콘
- 일반 화면과 예식 당일 화면의 네이버지도/카카오맵 버튼에 각 서비스의 공식 웹사이트 아이콘을 추가했습니다. 기존 지도 링크는 변경하지 않았습니다.
- 아이콘은 로컬 PNG로 포함되어 청첩장을 열 때 외부 아이콘 서버에 접속하지 않습니다.
- 네이버지도 원본: https://ssl.pstatic.net/static/maps/assets/icons/favicon.ico
- 카카오맵 원본: https://map.kakao.com/favicon.ico
- 아이콘은 각 서비스 식별 및 연결 표시를 위해 사용하며, 해당 상표 권리는 각 권리자에게 있습니다.

## 7차: 하객 미션 제거
- 오늘의 작은 미션 섹션과 추첨 스크립트·관련 스타일을 제거했습니다.
- 이름 5번 누르기, 감사 편지, 예식 당일 안내, 지도 아이콘은 유지합니다.
